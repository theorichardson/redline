Typography demo for Redline

  • Load the unpacked extension from dist/, activate Redline, then inspect these blocks.
  • Shift (hold): alignment guides
  • Hover tooltip shows font-size, font, and line-height whenever the hovered node has text
  • Cmd/Ctrl (hold): freeze the hovered element
  • Open the panel and expand Details for the same typography fields when an element has text.
